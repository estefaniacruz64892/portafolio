Sobre mí

Soy estudiante de Ingeniería Informática y trabajo en el área de analítica y automatización de Recursos Humanos en Crack the Code. Mi foco es eliminar tareas repetitivas y darle a los equipos información confiable para decidir.

Trabajo a diario con GAS, Google Sheets, Looker Studio, Metabase y SQL. Ahora estoy fortaleciendo mis bases de desarrollo web con HTML semántico y accesible.

Preguntas frecuentes

¿En qué tipo de proyectos puedo ayudarte?

Automatización de procesos repetitivos, dashboards de seguimiento y organización de datos operativos para que tu equipo trabaje con información confiable.

¿Qué herramientas usas?

Principalmente el ecosistema de Google (Apps Script, Sheets, Looker Studio), Metabase y SQL. Para la web, HTML, CSS y JavaScript sin frameworks cuando el proyecto lo permite.

¿Por qué este sitio no usa librerías?

Para demostrar que el navegador ya trae lo necesario: <dialog> para modales, <details> para acordeones, validación nativa de formularios y Web Components para reutilizar código.
